Recommended install flow

  1. Build or download the plugin jar.
  2. Place it in your server's plugins folder.
  3. Start the server and watch console output for first-run setup instructions.
  4. Create the master account, register 2FA, and configure roles before inviting other users.
  5. Use the panel on a trusted network first, then harden your public deployment separately.

Deployment notes

This is a server administration panel. Anyone with high permissions can affect real server state.

  • Use strong passwords and 2FA for every important account.
  • Do not expose the panel publicly without understanding your network and transport setup.
  • Back up worlds and plugin data before large changes.
  • Review permissions carefully before giving access to file, console, inventory, or role tools.
  • Prefer testing on a staging server before using new builds in production.
