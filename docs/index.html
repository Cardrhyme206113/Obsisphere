Current capabilities

Everything an admin reaches for, without tab-hopping.

Server monitoring, moderation, file work, permissions, logs, and live tools live in one place, with enough control to separate casual helpers from trusted staff.

01

Realtime server dashboard

Memory, CPU, players, TPS, MSPT, loaded chunks, entities, server info, uptime, MOTD, and stop controls.

02

Full file manager

Create, upload, edit, preview, rename, move, copy, delete, zip, download, archive, and extract server files from the browser.

03

Players, bans, ops, whitelist

Moderation tools for online and known players, dedicated ban list, pardon actions, whitelist control, and operator management.

04

Live map and inventory tools

Track players, inspect activity, view coordinates and vitals, and edit online or offline player inventories.

05

Roles, users, and 2FA

Master bootstrap, TOTP setup, forced onboarding, role inheritance, direct permissions, presence, and account settings.

06

Logs and audit trails

Activity logs, audit logs, failed authentication review, player movement and interaction snapshots, and panel notifications.

Feature history

From core panel to serious admin suite.

Obsisphere started as a control panel and grew into a full admin workspace with account security, detailed roles, logs, and live server tools.

Phase 1

Core panel foundation

Dashboard, file manager, players, plugins, worlds, live map, inventory, scheduler, x-ray watch, console, logs, themes, and responsive layout.

Phase 2

Security, permissions, and depth

2FA onboarding, users and roles, command policies, database-backed logs, failed-auth tooling, LAN-only mode, i18n, and PlayHosting theme polish.

Phase 3

Integrations and hardening

Planned work includes deeper deployment hardening, remote file access, broader version support, and plugin integrations.

To be implemented
