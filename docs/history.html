Product history

Two generations of Obsisphere.

V1 is the original panel generation preserved by the retired README. V2 is the current generation: the same project expanded into a deeper multi-admin, security-aware, mobile-capable server management application.

V2CURRENT GENERATION
2026 · ACTIVE DEVELOPMENT
CURRENT

Obsisphere V2

V2 is the current panel line. It keeps the core administrative scope of V1 and adds the systems that make the panel viable for multiple staff members and heavier day-to-day use: first-run bootstrap, TOTP 2FA, users and roles, direct and inherited permissions, command policies, database-backed logs, richer player tooling, current mobile work, server chat, global backgrounds, realtime notifications and the modern WebGL map/cache stack.

Major V2 additions

  • Master-account bootstrap and TOTP 2FA
  • Users, multiple roles and inherited/direct permissions
  • Per-user and per-role console command policy
  • Database-backed audit and player activity logs
  • Separate Players, Bans and Failed Auth pages
  • Expanded player statistics and export controls
  • Realtime admin/player activity toast notifications
  • Server chat page
  • Modern responsive mobile navigation shell
  • Global server-backed panel/login background
  • Modern 3D WebGL map architecture and caches
  • Current performance/lifecycle hardening

Current engineering focus

  • Reduce aggressive live-map polling where safe
  • Move more chunk encoding work away from Minecraft main thread
  • Improve SSE/journal efficiency under multiple clients
  • Continue cache bounds and lifecycle cleanup
  • General dashboard/file/log performance hardening
  • Long-tail UI and theme consistency
  • Transport and public-deployment hardening
  • Future integration and compatibility work
V2EXPANSION MILESTONES

From control panel to admin workspace.

The post-V1 work is where Obsisphere stopped being mainly a collection of admin pages and became a connected workspace. Permissions became granular, auditability moved into a database, player views gained context, the map became a dedicated renderer/cache subsystem, and settings started behaving consistently across desktop and mobile clients.

ACCESS

Security & staff model

2FA, onboarding, session-aware users, roles, dependencies and command policies.

DATA

Logs with depth

Activity and audit history moved from lightweight legacy storage into database-backed records.

LIVE

Realtime tooling

Notifications, richer player state and a more capable live map became part of normal workflows.

LEGACY PRODUCT GENERATION

Obsisphere V1

V1 established the product’s core identity: an embedded web control panel for Minecraft server administration. The retired README documents this generation’s dashboard, file manager, player tools, plugins, worlds, backups, live map, inventory editing, scheduler, X-Ray Watch, console, logs, themes and responsive layout.

Core administration

  • Realtime dashboard graphs and server information
  • Browser file manager and text/media workflows
  • Online player moderation
  • Whitelist and operator management
  • Installed plugins and remote resource search/install
  • World manager, backups and world settings

Live / utility tooling

  • Live block map with pan, zoom and player tracking
  • Online/offline inventory inspection and editing
  • Timed multi-step command scheduler
  • X-Ray Watch
  • Realtime console
  • Activity and audit viewers
  • Themes and mobile-aware layout work
